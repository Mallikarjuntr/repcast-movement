# spotter-movement

An open-source movement engine that turns body pose landmarks (e.g. from MediaPipe Pose) into **reps**, **holds** and **form feedback**.

- **Rep detector** — cyclic movements like squats, lunges and jumping jacks, with depth and form checks
- **Hold detector** — static poses like planks and yoga asanas, with alignment tolerance and wobble tracking
- **Exercises as data** — each exercise is a JSON definition, so adding a new one needs no new code

Used by [Spotter](https://github.com/Mallikarjuntr/spotter-tv-app). Documentation and examples are coming soon.
